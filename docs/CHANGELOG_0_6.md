# 0.6.0

- HTTP 工具增加 field 模式；原 legacy 模式保留，工具总数仍为 12。
- 逐字段、逐出现值记录帧、时间、显示转换、检测种类和抓包 SHA-256。
- 新增 `pcap-mcp-verify`，只读重提取；哈希变化、错误值、截断和空记录不作为通过。
- Agent 固定 HTTP 输出模式；新增可选 claims 报告，枚举事实与推测分开。
- Baseline 记录实验模式、字段核验、限定事实结果和 clean 用例的意外警告。
- 新增五种标准库生成的合成 PCAP 与测试。
- 真实 tshark 测试发现 HTTP 非 ASCII 显示值可能有损；改用 PDML 字段字节的显式 UTF-8 策略，记录取值方式、解析器替换字符与版本，失败时保留显示值且不猜测原文。
- 不增加第三方依赖；升级保留既有虚拟环境和历史实验。

上传 ZIP 不包含原客户端 scripts，本更新不覆盖本地旧脚本。本环境验证范围见 VALIDATION.md。
